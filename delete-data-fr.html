Demander la suppression des données

SmartScan est une application de numérisation de documents et d’OCR qui vous aide à numériser, organiser, rechercher et sauvegarder vos documents.

Cette page explique comment supprimer vos données SmartScan. SmartScan stocke vos documents sur votre appareil et, uniquement si vous choisissez la sauvegarde Google Drive, dans votre propre compte Google Drive. SmartScan n’exploite ni stockage cloud ni serveur pour vos documents.

Ceci est une traduction de la page en anglais, fournie pour votre commodité. En cas de différence, la version anglaise prévaut.

1. Quelles données SmartScan stocke-t-il ?

La plupart des données SmartScan vous appartiennent et se trouvent à l’un des deux endroits :

  • Sur votre appareil : images de documents numérisés, texte OCR, index de recherche, préférences de l’application et informations de connexion stockées localement.
  • Dans votre Google Drive : si vous activez la sauvegarde Google Drive, les documents sélectionnés que vous choisissez de sauvegarder sont stockés dans votre propre compte Google Drive.

SmartScan n’exploite aucun serveur qui stocke vos documents ou votre texte OCR.

2. Supprimer les documents stockés sur votre appareil

Pour supprimer des documents et leur texte OCR de votre appareil :

  • Ouvrez SmartScan et allez dans l’onglet Fichiers.
  • Sélectionnez le ou les documents à supprimer.
  • Utilisez l’option de suppression pour les retirer.

Pour supprimer d’un coup toutes les données SmartScan de votre appareil, vous pouvez aussi :

  • Ouvrir les paramètres de votre appareil Android, aller dans Applications, sélectionner SmartScan, puis choisir Effacer le stockage ou Effacer les données, ou
  • Désinstaller SmartScan.

Effacer les données de l’application ou la désinstaller supprime de votre appareil les documents stockés localement, le texte OCR, les informations de connexion et les préférences de l’application.

3. Supprimer les documents sauvegardés dans Google Drive

Si vous avez utilisé la sauvegarde Google Drive, vos documents sauvegardés sont stockés dans votre propre compte Google Drive. Supprimer SmartScan de votre appareil ne supprime pas ces fichiers.

Pour supprimer des documents sauvegardés :

  • Ouvrez le dossier de sauvegarde SmartScan dans votre Google Drive, ou
  • Ouvrez SmartScan, allez dans l’onglet Cloud et supprimez-y les fichiers.

Comme ces fichiers sont dans votre compte Google Drive, vous pouvez les gérer ou les supprimer définitivement via votre Google Drive.

4. Retirer l’accès de SmartScan à votre compte Google

Pour empêcher SmartScan d’accéder à votre compte Google :

  • Ouvrez SmartScan, allez dans Paramètres et déconnectez-vous, ou
  • Ouvrez votre compte Google, allez dans Sécurité et gérez l’accès des tiers pour retirer SmartScan.

5. Demander une suppression supplémentaire

SmartScan n’exploite pas son propre serveur cloud ; il n’y a donc ni documents ni données personnelles stockés sur un serveur exploité par SmartScan à supprimer.

Si vous avez une demande de suppression non couverte par les étapes ci-dessus, contactez-nous à : aenage@gmail.com en précisant votre demande et le compte Google utilisé avec SmartScan (le cas échéant).

6. Que supprime-t-on et que garde-t-on ?

Lorsque vous supprimez vos données avec les étapes ci-dessus :

  • Les documents, images et texte OCR stockés sur votre appareil sont supprimés.
  • Les informations de connexion stockées localement (comme votre nom et votre adresse e-mail) sont supprimées.
  • Les préférences de l’application et l’index de recherche sont supprimés.
  • Les documents sauvegardés dans votre propre Google Drive ne sont pas supprimés automatiquement. Ils restent dans votre Google Drive jusqu’à ce que vous les supprimiez, car ils sont dans votre compte, pas dans SmartScan.

7. Conservation des données

SmartScan ne maintient pas sa propre base de données cloud contenant vos documents numérisés.

Les documents stockés localement restent sur votre appareil jusqu’à ce que vous les supprimiez, effaciez les données de l’application ou désinstalliez l’application.

Les documents sauvegardés dans Google Drive restent dans votre Google Drive jusqu’à ce que vous les supprimiez ou qu’ils soient retirés selon vos paramètres Google Drive.

Les informations traitées par des services tiers comme la connexion Google, Google Drive, Google AdMob, les services d’analyse et de rapports de plantage, et Google Play sont soumises aux politiques de conservation respectives de ces services.
